# Changelog

All notable changes to ZAY-RIce are documented here.

## [1.0.0] - 2026-07-27

### Added
- Initial public release of ZAY-RIce
- Tokyo Night Synth color palette — static and Wallust dynamic modes
- Pure standalone Hyprland session (zero KDE Plasma dependencies)
- Vertical side dock with squircle app buttons and active/running indicators
- Top Waybar with workspaces, window title, MPRIS media, system monitors
- Custom hyprlock screen with blurred wallpaper and live clock
- Hypridle: auto-dim → lock → DPMS off → suspend pipeline
- Kitty and Foot terminals at 0.75 opacity
- VSCode 0.75 opacity via Hyprland windowrulev2
- 3 bundled wallpapers (Tokyo lofi, dark purple figure, samurai warrior)
- Dynamic wallpaper switching via `wallpaper.sh` with Wallust palette regeneration
- SDDM Tokyo Night login theme with `setup_sddm.sh` installer
- `deploy.sh`: safe deployment with automatic backup and rollback instructions
- Wofi app launcher with Tokyo Night Synth stylesheet
